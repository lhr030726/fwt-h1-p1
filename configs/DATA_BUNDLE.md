# 可迁移的 H1/P1 开发数据

发布数据版本为 `rcda-h1-data-v1`。仅包含冻结划分中的 Tb 3,197、Tr 811、V 568 个样本，共 9,152 个原始 `.npy` 文件。原始字节、样本/事件身份、输入日、次日目标、角色、空间参考与归一化数值保持原样。此数据包不包含概率校准、风险校准或最终评估数组，也没有重新划分数据。

原始数组共 14,695,915,520 字节。采用独立 `tar.gz` 分片，元数据与数组分开；每片原始 tar 有效负载不超过 960 MiB，最终压缩文件必须小于 1 GiB。压缩率以实际构建回执为准，不依据文件扩展名假定。打包脚本只流式读取原字节并核对既有审计 SHA256，不导入 NumPy/Torch、不解析数组或重新拟合统计。

仓库内 `data-index.json` 是下载信任根。GitHub Release 中的同名文件必须逐字节一致；其中每个分片和每个文件都记录大小及 SHA256。下载器只提取清单中 `data/` 下的普通文件，拒绝路径越界、链接、重复成员、未列成员以及覆盖已有不同内容。最终数据根为 `data/`：

- `bundle.json`：数据范围、角色计数及运行文件绑定。
- `manifest.json`：仅三个开发角色；输入和标签路径为相对路径。
- `normalizer.json`：原完整 Tb 拟合统计，仅迁移天气清单路径及其 SHA。
- `config.h1.json`：与仓库 `configs/h1.json` 同字节，其他模型与数据设置保留旧正式候选。
- `arrays_index.json`：每个样本 input/label 的角色、相对路径、大小与 SHA。此文件中的 `path` 相对仓库安装根，以 `data/` 开头；manifest 内的路径相对 `data/`。
- `weather_manifest.json` 与 `evidence/`：原字节天气来源闭包及受限路径映射。

天气包装 schema 为 `fwt_power_portable_manifest_v1`。原 Windows 路径仅作为来源身份键，运行时映射到包内证据，不能访问旧电脑的磁盘。原 v2 的 `RAW_HTTP` 与 `DERIVED` 区别、24 个输入日 UTC 小时、来源响应、逐日精确抽取、原始失败与恢复请求、收据、脚本及 HTTP 头均保留，由原语义验证器逐项核验。不会将派生天气伪装成原始下载结果。历史 curl 可执行文件只保留已有身份记录，不打包、不执行。

完整六角色原 manifest 作为不可变来源证据保留，运行数据集仅加载开发清单；历史证据中的其他盘符、校准或最终角色路径不授权读取其数组。历史暴露限制同原记录保留，不能把这些角色重新称作从未见过的独立测试集。

此包是既有研究数据的可迁移封装，不是新的训练结果。H1/P1 的科研协议与短训/正式训练输出隔离由服务器入口另外检查；构建数据包不启动任何训练或评估。
